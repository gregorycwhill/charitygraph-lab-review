# CharityGraph Semantic Lab review surface

This temporary public repository is a review-only surface for sanitised CharityGraph Semantic Lab artefacts. It is not the CharityGraph production dataset and is not the private forensic diagnostics archive.

Raw source representations, full evidence packets and raw provider traffic remain private. Public artefacts contain model-derived propositions, validation diagnostics, hashes/IDs and bounded source excerpts. Source excerpts remain attributable to and copyrighted by their source owners; no open-source licence is applied to third-party excerpts.

This publication should be treated as permanently public even if repository visibility later changes.
